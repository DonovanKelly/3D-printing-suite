Projects can now be renamed, saved as portable `.print-workspace` files, and reopened entirely on the client. Files embed the original artwork, settings, project name, and selected preview tab. An optional Restore on return setting keeps the latest workspace in this browser using IndexedDB. Downloads follow the editable project name; no server storage is required.

The border can use the image filament, the background filament, or a third configurable color. Linked borders follow color changes. Independent borders are separate, aligned material parts in the preview, STL pack, and 3MF, with consistent Bambu logical filament assignments: background 1, artwork 2, border 3. All border profiles preserve the original combined shape and dimensions. Removing a border preserves its selection but omits its extra material.

Workspace format version 2 preserves the new border settings; version 1 files and browser recovery records migrate to the original image-colored border. Invalid documents leave the current project intact. Application branding remains unchanged pending a name choice.

Validation: `bash scripts/check.sh` passes Rust formatting/Clippy and 12 Rust tests, Ruff and 366 Python tests, TypeScript checks, the production Wasm/web build, and 46 desktop/mobile browser tests. The 18 pre-existing optional Python cases remain skipped because their external artwork/slicer prerequisites are unavailable. New checks independently reopen material STLs/3MFs, verify closed non-overlapping parts and preserved total volume, inspect Bambu filament metadata, and exercise workspace migration and browser recovery. Screenshots, a saved workspace, a three-color 3MF, a full print pack, and verification reports are preserved in shared review storage outside Git.

Actual AMS tray mapping, desktop Bambu Studio slicing, physical fit, and mounting strength remain manual checks. No printer jobs are dispatched.
